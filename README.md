# CookieBadz

A simple Cookie Clicker cheat/menu script that adds a floating menu with options to modify cookies, sugar lumps, buildings, building levels, and some stock market minigame values.

## Features

- Add or set cookie amount
- Set cookies per second (CPS)
- Add sugar lumps
- Set amount of any building
- Set level of any building
- Stock Market modifier (brokers, office level, profits, tick speed, stock values, stocks owned)
- Open the official Cookie Clicker Dev Tools
- Clear save data
- Draggable menus

> **Note:** Other minigames (Wizard Tower, Temple, Garden, Workshop) are **not** implemented yet. The buttons exist but currently just show an alert.

## How to Use

1. Open this repository and click the **raw** button on the script file (or copy the entire script).
2. Go to the official **Cookie Clicker web version**:  
   [https://orteil.dashnet.org/cookieclicker/](https://orteil.dashnet.org/cookieclicker/)
3. Press `F12` (or right-click → Inspect) to open the browser console.
4. Type `allow pasting` and press Enter (required in most modern browsers).
5. Paste the entire script into the console and press Enter.
6. The yellow **CookieBadz** menu should appear.  
   You can drag it around, minimize it, or close it.

That's it — you're done!

## Notes

- The script waits for the game to fully load before creating the menu.
- Some features (especially Stock Market tools) only work after you have unlocked the Bank building and its minigame.
- Use at your own risk. This is for fun / single-player only.
